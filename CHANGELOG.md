# Changelog

## v0.1.17 - Mara Endurance Training

- Added a 30-minute endurance challenge to Mara's pet-room hub.
- Added six five-minute intervals with escalating Willpower checks.
- Each interval adds 500 player arousal.
- Passing all six checks grants +2 Mara Dominance and +1 Trust.
- Failing a check reduces Willpower by one and routes the player to the discipline room.
- Added a stop option that ends the event without a failure penalty.
- Tweego compilation succeeded for the v0.1.17 development tree.
- Browser runtime testing remains outstanding for stage transitions, Willpower balance, arousal changes, and failure routing.
